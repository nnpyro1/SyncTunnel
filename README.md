# 软件简介
这个软件本来只支持文件同步的，现在开始支持远程管理功能了。下面是一些功能：
- **AES-256-CBC加密** 数据传输全程采用AES加密，安全有保障
- **DTATC（双轨自适应传输控制）文件同步** 自创DTATC拥塞控制算法，公网环境中(80ms RTT,5%固定丢包)表现超出了基于多对等客户端和NAT穿透的文件同步工具发送速度的表现 **（因为这个软件本来设计出来就是在公网环境通信的）**
- **远程拉取文件** 直接拉取一台运行了SyncTunnel的电脑上面的任意文件
- **远程控制** 远程控制一台电脑。（虽然有点卡）
- **远程关机** 远程关机一台电脑
- **文件挂起** 一台电脑关机之前挂起文件，这台电脑关机之后其他电脑仍然可以下载。
- **DFHN** 创新实现了DFHN功能，可以直接把客户端作为分布式文件挂起节点（DFHN），完美解决Github挂起速度慢的问题，更可以直接当做NAS平替，仅需要树莓派等便宜的微型电脑就可以当做NAS平替
